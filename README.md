Terminal-based personal calendar and task management.

1. Project Goal

Time management, managing deadlines, but I can customize it.

2. Minimum Viable Product (MVP)

Working calendar and todo list.

Core Features

Feature| Description
Task Creation| Add tasks with a title, description, and relevant dates.
Task Management| View, edit, and delete existing tasks.
Task Completion| Mark tasks as completed or reopen them.
Data Persistence| Save and load tasks using local files.
Calendar View| Display tasks organized by date.
Daily Overview| View today's tasks and upcoming deadlines.
Task Scheduling| Assign and modify scheduled dates and deadlines.

Task Attributes

Each task will contain the following information:

- Task ID
- Title
- Description
- Scheduled Date
- Deadline
- Completion Status
- Priority
